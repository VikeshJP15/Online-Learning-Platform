# EduFlow — Learn Anything

A modern multi-subject online learning platform. Browse courses in Programming, Design, Data Science, AI & ML, Business, Music, and more. Track your enrolled courses and follow structured learning roadmaps.

## Features

- Multi-subject course catalog (12+ courses across 6+ subjects)
- Search and filter by category
- Enroll / drop courses with progress tracking
- Learning roadmaps (Software Dev, Product Design, Data Analyst, AI Engineer)
- Personal dashboard with stats
- Progress saved in browser

## Run locally

Open `frontend/index.html` in any browser — no server needed.

## Publish on GitHub Pages

1. Open the repository on GitHub.
2. Go to `Settings` > `Pages`.
3. Under `Build and deployment`, choose `GitHub Actions`.
4. Push to `main` or run the `Deploy frontend to GitHub Pages` workflow manually from the `Actions` tab.
